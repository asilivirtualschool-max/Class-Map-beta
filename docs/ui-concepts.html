How to read these

Every concept shows the same eight students at the same moment of the same lesson, so the only variable is the design. Switch to Phone to see what a student holds, and Projector to see what goes on the wall — several of these behave very differently at the two sizes, and that is usually what decides it.

The five map concepts are structurally different, not restyled versions of each other. The three dashboards are alternative answers to one question: what should a teacher see first when they glance up?
